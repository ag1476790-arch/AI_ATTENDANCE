1. Images as NumPy Pixel Matrices

OpenCV's BGR vs standard RGB

In OpenCV, any digital image is represented as a multidimensional NumPy array with shape (Height, Width, Channels):

# BGR order: Blue (index 0), Green (index 1), Red (index 2)
pixel = frame[y, x] # [B, G, R] values (0-255)
gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY) # 1-channel intensity

Why BGR? Early hardware cameras and graphics cards (like BGR framebuffers) stored blue first for historical reasons. OpenCV maintained this convention for backward compatibility.

2. VideoCapture & Threaded FPS

Handling 30 FPS without blocking the web server

A video is a rapid sequence of still image frames. In Python, calling cap.read() is a blocking I/O operation waiting on hardware driver buffers.

cap = cv2.VideoCapture(0, cv2.CAP_DSHOW)
ret, frame = cap.read()
# Run in dedicated background thread with Lock()

Our system uses a dedicated daemon thread to continuously grab frames, storing only the latest frame in memory. This eliminates hardware buffer delay and ensures smooth 30+ FPS video streaming.

3. Face Detection vs Face Recognition

The most important distinction in computer vision

Face Detection "Where is a face?"

Locates bounding box coordinates (x, y, w, h) of any human face.

Face Recognition "Whose face is this?"

Extracts identity features and matches against the enrolled student database.

You cannot recognize a face without first detecting where it is! Detection is step 1; recognition is step 2.

4. Deep Face Embeddings (SFace)

128-dimensional hyperspace vectors

Rather than comparing raw pixels (which fail when lighting or head pose changes), our system uses OpenCV's SFace deep neural network to map every face into a 128-dimensional unit vector:

Rahul → [0.124, -0.043, 0.812, ..., -0.321] ∈ ℝ128
Cosine Similarity: cos(θ) = (A · B) / (||A|| × ||B||)
# Match threshold ≥ 0.363 means same identity!

Vectors of the same student cluster closely together in space, while different students point in different directions.

5. Coordinate System & HUD Drawing

Top-left origin (0, 0) geometry

OpenCV image coordinates start from the top-left: X increases to the right, Y increases downwards.

# Bounding Box: (x, y) = top-left, w = width, h = height
cv2.rectangle(frame, (x, y), (x+w, y+h), (0, 255, 0), 2)
cv2.putText(frame, "Rahul - Present", (x, y-10), ... )

We draw rounded tech corners and badge backgrounds to produce a professional heads-up display (HUD).

6. Liveness & Deduplication Logic

Preventing photo spoofing & duplicate records

To prevent fraud and maintain database integrity:

  • Laplacian Variance: Measures high-frequency edge texture to detect blurry printed photos.
  • Database UNIQUE(roll_number, date): Guarantees a student can only be marked present once per calendar day.
  • Memory Cooldown: 15-second debounce window prevents continuous re-triggering while a student walks through.
